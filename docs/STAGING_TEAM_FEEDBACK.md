# Staging Team Feedback

Use this as the description and question set for a private Google Form, Microsoft Form or project issue form. Keep the staging URL and feedback form restricted to the team until organiser access is secured.

## Intro

Please test the Indra Jatra visitor app on your own phone. We are checking whether visitors can understand what is happening, find key places and complete registration without help. Do not enter sensitive personal information; use a team test email and phone number.

## Tester Details

- Name or initials
- Device: iPhone / Android / desktop
- Browser and version
- Installed to home screen: Yes / No / Could not install

## Task Checklist

Ask testers to complete these tasks before answering:

1. Register using the email code.
2. Sign out and sign in again.
3. Find what is happening now and next.
4. Locate First Aid, toilets and entry/exit on the map.
5. Open one cultural trail story and collect a stamp.
6. Save one programme item.
7. Open the sponsorship-interest form.
8. Try the app once with poor connectivity or airplane mode.

## Questions

1. How easy was registration and sign-in? Scale 1-5.
2. Did the email code arrive? Yes / No / Delayed. If delayed, approximately how long?
3. Could you tell what was happening now and next? Yes / Partly / No.
4. Could you find First Aid and toilets without help? Yes / No.
5. Was any wording confusing? Long answer.
6. Did anything look broken, overlap or require zooming? Long answer.
7. Which screen felt most useful? Home / Programme / Map / Explore / My Festival / Other.
8. Which task was hardest? Long answer.
9. Did installation to the home screen work? Yes / No / Did not try.
10. What is the single most important improvement before public launch? Long answer.

## Bug Evidence

For every bug, request:

- page or screen name;
- exact action taken;
- expected result;
- actual result;
- screenshot or screen recording;
- device, browser and approximate time.

Do not collect passwords, login codes, database details or private attendee data in the feedback form.
